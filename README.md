🗄️ Verilənlər Bazasının İdarəetmə Sistemləri (VBİS) — Universitet Layihələri

Bu repositoriya universitetin Verilənlər Bazasının İdarəetmə Sistemləri (VBİS / DBMS) fənni çərçivəsində hazırlanan laboratoriya işlərini, praktiki tapşırıqları və SQL skriptlərini əhatə edir.

Repositoriyanın əsas məqsədi relasiyalı verilənlər bazası modellərinin qurulması, normallaşdırılması (1NF - 3NF), T-SQL skriptlərinin yazılması və verilənlər bazasının idarə edilməsi üzrə praktiki bacarıqları toplamaqdır.

📂 Layihə və Laboratoriya İşləri Siyahısı

Sistemdə təqdim olunan laboratoriya tapşırıqları və mövzular:

Elektrik Malları Zavodunun Uçotu Sistemi — Relasiyalı DB strukturu, xammal və hazır məhsul uçotu, satış və qalıq borcların hesablanması (elektrik_mallari.sql).

(Gələcək laboratoriya işləri buraya əlavə olunacaq)

🛠️ İstifadə Olunan Texnologiyalar

DBMS: Microsoft SQL Server (MS SQL)

Sorgu Dili: T-SQL (Transact-SQL)

Mühit: SQL Server Management Studio (SSMS) / Azure Data Studio

🚀 Repositoriyadan İstifadə Addımları

Repositoriyanı lokal kompyuterinizə klonlayın:

git clone https://github.com/USERNAME/REPOSITORY_NAME.git


MS SQL Server Management Studio (SSMS) proqramını işə salın.

İcra etmək istədiyiniz laboratoriya işinin .sql faylını SSMS-də açın.

Execute (F5) düyməsini sıxaraq verilənlər bazasını və cədvəlləri yaradın.
